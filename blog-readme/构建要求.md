# 博客构建要求（可持续更新）

你可以随时改这个文件，我会以最新版本为准。

## 1) 文章基础规则

- 输入来源：`blog-readme/` 目录下的 `*.md`
- 输出目标：生成到博客可发布结构（与现有站点兼容）
- 默认语言：中文
- 默认读者：技术岗位面试官 + 工程实践读者

## 2) 默认 front-matter 规范

- `title`: 从正文主题提炼，避免空泛标题
- `date`: 使用你指定时间；未指定时用当前时间
- `tags`: 3~6 个，避免重复
- `categories`: 1~2 级
- `description`: 80~140 字摘要

## 3) 内容结构规范

- 开头：问题背景 + 结论预览
- 正文：按“步骤/方案/对比/踩坑”展开
- 结尾：结果总结 + 可复用清单
- 代码块：必须标注语言
- 命令行：给出可直接执行版本，避免省略关键参数

## 4) 风格要求

- 少空话，多结论和可操作步骤
- 关键风险点要明确标注
- 术语首次出现给一句解释
- 避免过度营销口吻

## 5) 发布前检查清单

- 标题与内容一致
- 标签/分类合理
- 代码和命令可读
- 链接有效
- 敏感信息已脱敏（密钥、邮箱密码、Token）
