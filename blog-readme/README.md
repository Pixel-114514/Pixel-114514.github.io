# 博客素材目录

这个目录专门存放你给我的博客素材与说明文档。

## 你怎么用

1. 把你写好的 `*.md` 草稿放到这里（可以一个或多个）。
2. 文件名尽量语义化，例如：
   - `2026-04-16-linux-代理踩坑.md`
   - `rag-检索优化实践.md`
3. 如果某篇有特殊要求（语气、结构、配图、SEO 关键词），在同目录加一个同名说明文件，例如：
   - `rag-检索优化实践.requirements.md`

## 我会做什么

1. 读取这里的 Markdown 源文档。
2. 按 `构建要求.md` 统一规范，整理为可发布博客页面。
3. 必要时补齐 front-matter（标题、时间、标签、分类、摘要）。
4. 更新站点页面并按你的指令提交/推送。
