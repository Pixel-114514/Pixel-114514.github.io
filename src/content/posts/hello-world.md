Welcome to my corner of the internet. This is where I'll share my thoughts on AI, software engineering, and the projects I'm working on.

## Why I'm Writing

Writing is thinking. By publishing my notes and learnings publicly, I hope to:

1. **Solidify my understanding** — if I can't explain it clearly, I don't understand it well enough
2. **Connect with others** — the best conversations often start from a blog post
3. **Build in public** — sharing the journey, not just the destination

## What to Expect

I plan to write about:

- **AI Agent architectures** — patterns, pitfalls, and practical lessons from building agent systems
- **LLM applications** — deploying and optimizing large language models
- **Reinforcement learning** — algorithms, implementations, and intuitions
- **Open source** — tools I build and contribute to
- **System design** — how to build reliable, scalable software

## The Stack

This blog is built with Next.js 14, TypeScript, and Tailwind CSS. It's statically exported and deployed on GitHub Pages. The design draws inspiration from code editors and terminal aesthetics — fitting for a developer's blog.
